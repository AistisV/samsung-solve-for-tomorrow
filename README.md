# Samsung Solve for Tomorrow 2026 — Idea Lab

Brainstorming repo for finding the strongest possible idea for **Samsung Solve for Tomorrow 2026 (Lithuania / Baltics)**.

## Contest in one screen

- **Who:** grades 9–12 in LT / LV / EE, teams of 3–5, one supervising teacher. One idea per team.
- **Themes (pick one):**
  1. **Sport & technology** — how can tech make sport more accessible, more educational, more meaningful? How can tech get students more active?
  2. **Sustainability** — how can tech help build a greener tomorrow / help us live more sustainably?
- **Language:** application in Lithuanian is fine; **the final is pitched in English.**
- **Original work only** — no copied text/images/audio/video.

## Strategy in one paragraph

**Specific problem, boring-reliable tech, scalable pattern.** Judges reward local realism (38.4), prior-art research (38.2), feasibility incl. law (48.4), reach to the target audience (48.6), transferability (48.3) and give a bonus for AI / IoT / VR / AR (48.7). So: a sharp, evidence-backed Lithuanian pain point → a technical mechanism a school team could actually demo → a clear story of how it scales to other towns / countries / policy.
