# Idea pool — Sustainability

Theme: *How can tech help us build a greener tomorrow? How can tech solutions help us live more sustainably?*

**Trap warning**: food-waste-with-AI already won (Minova, 2022). "Recycling-sorting app" and "carbon-footprint tracker" are the sustainability equivalents of "gamified step app".

Legend — Verdict: 🟢 shortlist · 🟡 maybe · 🔴 drop (reason).

## A. Invisible local problems → make them visible

| # | Idea | Tech | Local hook | Verdict |
|---|---|---|---|---|
| E1 | **Well-Check** — €0.30 nitrate test strip + phone camera → AI reads colour accurately → private well gets a result + an anonymised national map of hotspots; schools run village-wide testing campaigns. | AI vision + map (citizen science) | 1 in 3 wells nitrate-contaminated; invisible; free tests only for pregnant/infant households | 🟢 |
| E2 | **Hogweed Hunter** — AI identifies Sosnowsky's hogweed from phone photos/drone; every patch geotagged; *regrowth tracked for 3 yrs* after removal (the actual failure mode); feeds municipal/2025–29 national programme. | AI vision + map | "Removal inconsistent, keeps regrowing"; state asks public to report | 🟢 |
| E3 | **Beetle Watch** — Sentinel-2 satellite + AI detects early spruce stress in *private* forests (255k owners, avg 3.4 ha, mostly passive) → SMS alert "check these trees" before the beetle spreads. | AI + satellite | 0.7–1.0 M m³ spruce lost/yr | 🟢 |
| E4 | **Smoke-watch** — PM2.5 sensor network at schools in small towns + map of heating-season pollution; teaches wood-drying. | IoT | Wood-smoke PM2.5 | 🟡 Sensor.Community exists |
| E5 | **Bloom alert** — citizen photos + satellite → cyanobacteria bathing map for Curonian Lagoon/lakes. | AI + satellite | Summer blooms | 🟡 decent, but seasonal & official monitoring exists |
| E6 | **Firewood moisture check** — phone-connected moisture meter + AI "is this wood ready?" | IoT | Wet wood = smoke | 🔴 too small |
